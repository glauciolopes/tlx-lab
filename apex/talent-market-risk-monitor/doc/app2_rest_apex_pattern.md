# REST Integration Pattern in Oracle APEX

This example demonstrates how to integrate a public REST API directly into an Oracle APEX application using native REST Data Sources.

The application dynamically retrieves economic indicators from the World Bank API and visualizes them using JET charts and an Interactive Report.

Users can select:

- Country
- Economic Indicator

The regions refresh asynchronously using Dynamic Actions.

The purpose of this project is to demonstrate a reusable integration pattern for building REST-driven dashboards in Oracle APEX.
